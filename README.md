# NulTTS

A completely free Vietnamese text-to-speech tool

### NulTTS is a free Vietnamese Text-to-Speech tool powered by OmniVoice.

## How to Build?
<a href="https://colab.research.google.com/github/NulTTS/NulTTS/blob/main/backend/Backend.ipynb"><img src="https://colab.research.google.com/assets/colab-badge.svg" alt="Open in Colab"></a>

Click Open in Colab above and run the notebook.

### Local
```
git clone https://github.com/nultts/NulTTS.git
cd NulTTS
jupyter notebook backend/Backend.ipynb
```
